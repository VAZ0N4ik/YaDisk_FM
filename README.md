# Яндекс.Диск Файловый Менеджер

Консольное приложение для просмотра и скачивания файлов с Яндекс.Диска через OAuth токен.

## Возможности

- 📁 Навигация по папкам Яндекс.Диска
- 📥 Скачивание отдельных файлов
- 📦 Множественное скачивание файлов (выбор нескольких файлов, диапазоны, все файлы)
- 🕐 Сортировка по дате изменения (новые файлы отображаются первыми)
- 🎨 Цветной интерфейс для удобной навигации
- 💾 Автоматическое создание папки для загрузок

## Требования

- Python 3.6+
- Яндекс OAuth токен

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/VAZ0N4ik/YaDisk_FM.git
cd YaDisk_FM
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

4. Откройте `.env` и вставьте ваш OAuth токен:
```
YANDEX_TOKEN=y0_AgAAAAABxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

## Получение OAuth токена

1. Перейдите на [https://oauth.yandex.ru/](https://oauth.yandex.ru/)
2. Создайте новое приложение
3. В настройках приложения выберите права доступа к Яндекс.Диску
4. Получите OAuth токен

## Использование

Запустите приложение:
```bash
python yadisk_fm.py
```

### Команды

- **[номер]** - открыть папку или скачать файл
- **[m]** - режим множественного выбора файлов
  - Введите номера через пробел: `3 5 7`
  - Используйте диапазоны: `3-7`
  - Выберите все файлы: `all`
  - Отмена: `cancel`
- **[..]** - вернуться в родительскую папку
- **[r]** - обновить текущую папку
- **[q]** - выход из приложения

### Примеры использования

1. **Скачивание одного файла:**
   - Введите номер файла
   - Подтвердите скачивание (y/n)

2. **Множественное скачивание:**
   - Введите `m`
   - Выберите файлы: `1 3 5` или `1-5` или `all`
   - Подтвердите скачивание

## Структура проекта

```
YaDisk_FM/
├── yadisk_fm.py           # Главный файл приложения
├── yandex_disk_client.py  # Клиент для работы с API Яндекс.Диска
├── console_interface.py   # Консольный интерфейс
├── file_downloader.py     # Модуль для скачивания файлов
├── requirements.txt       # Зависимости
├── .env.example          # Пример файла с токеном
├── .gitignore           # Игнорируемые файлы
└── downloads/           # Папка для скачанных файлов (создается автоматически)
```

## Особенности

- Файлы скачиваются в папку `downloads/` в директории приложения
- При совпадении имен файлов автоматически создаются уникальные имена
- Поддерживаются все типы файлов
- Отображается размер файлов и дата последнего изменения
- Безопасная обработка путей и имен файлов
